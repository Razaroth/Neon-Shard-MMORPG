# Neon Shard visual preview

The first stylized art pass for Neon Shard, an original cyberpunk online game built in Godot.

## Character selection

Five original classes: Vanguard, Cipher, Ronin, Ghost, and Machinist, with five character slots per server.

## City district

Isometric neon buildings, storefronts, streetlights, rain, and the central relay terminal.
